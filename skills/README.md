# Claude skills for this MCP

These skills teach Claude how to use the studio tools in this fork. Keep them in sync with the code.

**Base skills (genre-neutral)**
- `ableton-mcp-studio`: operating Live through the tools; the set → render → measure → compare → ask loop.
- `music-production-craft`: theory, groove, sound, arrangement and mix, and how they interact.
- `bell-curve-breakers`: a cliché detector and a quantified curveball deck.

**Genre and colour layers**
- `genre-disco-house`: disco, nu-disco, disco house, French filter house, jazz house.
- `colour-maqam-fusion`: maqam, microtones, iqa'/usul rhythms, ney, saz, oud and darbuka.

New genres get their own `genre-*` skill, so the base skills stay generic.
